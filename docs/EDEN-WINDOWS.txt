Switch TV Box — Windows / Eden 自动组播

使用方法
1. 将整个 ZIP 解压到一个文件夹，保留 _internal 和其他配套目录。
2. 在 Eden 中打开 Switch TV Box NRO，保持图形首页运行。
3. 双击 Switch-TV-Box-Discovery.exe，保持窗口打开。
   无需填写 IP、选择网卡或安装 Python。它会自动找到正在运行的 Eden，
   在已连接的物理网卡上发布 AirPlay / RAOP 和 DLNA 设备。
4. 手机音乐面板的 AirPlay 列表或视频应用的 DLNA 投屏列表中选择 Switch TV Box。

手机与 Windows 电脑需要处于允许设备互访和组播的局域网。
组播自动发现不能穿越不转发组播的路由器、访客隔离或互不相通的网络。
如 Windows 弹出网络访问提示，允许 Eden 和本组件访问当前家庭/专用网络。
组件不会修改防火墙、系统路由、VPN、Eden 配置或手机设置。

窗口显示 Automatic discovery active 后，表示已读取真实接收器身份并发布设备。
Waiting 表示接收器尚未启动、网络暂不可用或端口无法访问，会自动重试。
退出 NRO 时自动撤销设备；再次启动会重新发布。断网、换 Wi-Fi 或地址变化后
自动更新。关闭组件窗口即停止它负责的发现广播。

功能范围
- mDNS: _airplay._tcp 与 _raop._tcp，使用 NRO 的真实身份、密钥和功能声明。
- SSDP: 加入 239.255.255.250:1900，周期 alive、搜索应答和退出 byebye。
- 自动忽略虚拟/VPN 网卡；同一网段的有线和无线连接仅发布一次。
- TCP 18958 只提供设备描述，并将控制、事件和资源地址指向实际 NRO 的 49152 端口。
- 配对、音频、视频、DLNA 控制和播放均由 NRO 完成；组件不接收媒体。

为什么 Eden 需要这个组件
Eden 的 IP 组播入组和接口选项尚未实现，NRO 无法替宿主操作系统完成这些调用。
本组件让 Windows 网络栈执行自动组播。实体 Switch 使用 NRO 自带的发现服务，
不需要运行此组件，也不应使用 eden-compat.flag。
